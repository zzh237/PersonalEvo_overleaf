# HyperRidge Paper

The current submission draft is `iclr2027_v8.tex`. It uses the official,
unmodified ICLR 2027 style in anonymous review mode.

Build from this directory:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error iclr2027_v8.tex
```

Select `iclr2027_v8.tex` as the root document when importing this repository
into Overleaf. Earlier versioned drafts are retained for reference.
